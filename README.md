# Roger Gammans

Software engineer and IT consultant. I've worked since 1993 across embedded
systems, Linux, backend development, networking and cloud, and I run a small
software development consultancy.

## What I'm working on

- Python/Django backends and data pipelines on Azure
- Kubernetes: a small cluster for internal services, and volunteer web
  infrastructure for UK Freeforms
- Rust, through Advent of Code and personal projects

## Projects here

- [mysterymachine](https://github.com/rgammans/mysterymachine): a
  documentation system built on reStructuredText. It works as a document macro
  system, putting text fields together into objects and generating documents
  from templates by running queries across a document database. The storage
  layer is a filesystem-based database with a write-ahead log.
- [k8senv](https://github.com/rgammans/k8senv): a shell subsystem that
  protects the kubeconfig file, removing it from disk when k8s isn't being
  accessed by an admin.

## Open source

I've been contributing to open source for a long time. I ported Linux to the
ARM-based Geofox One palmtop, and was part of the first successful Linux boot
on the arm-7110 platform. I've also worked on the Linux kernel (including
hardware driver debugging) and wxWidgets, and wrote the DocBook documentation
for the JBD layer of the ext3 filesystem.
